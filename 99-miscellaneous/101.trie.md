# 트라이(Trie)란 무엇인가?

## 트라이의 활용

트라이(Trie)는 딕셔너리(dictionary)와 유사한 문제에 유용하다. 트라이를 사용하면 부분 문자열(sub-string)을 조회(lookup)하여, 그 부분 문자열로 시작하는 모든 문자열을 빠르게 찾을 수 있다.

## 예시: 자동완성(Auto-complete)

예를 들어, 다음과 같은 단어들을 포함한 Trie 가 있다고 하자.

```
Trie: [cat, catalyst, catastrophe, dog, rat, dogmatic]
```

자동완성(auto-complete) 기능을 구현한다고 가정해보자. 사용자가 검색어를 입력하기 시작하면, 추천 검색어(suggested queries)를 보여주고자 한다.

사용자가 `"cat"` 을 입력했다고 하면, Trie 를 사용해 `"cat"` 으로 시작하는 가능한 단어들을 빠르게 반환할 수 있다:

```
[cat, catalyst, catastrophe]
```

이 결과를 추천 검색어로 보여줄 수 있다.

## 배운 점:
- Trie 는 문자열의 접두사(prefix)를 기준으로 데이터를 조회하는 데 최적화된 자료구조이다.
- 자동완성, 사전 검색 등 "특정 문자열로 시작하는 모든 항목 찾기" 문제에 적합하다.
- 부분 문자열 하나를 조회하면 그 이후의 모든 하위 경로(sub-tree)를 빠르게 탐색할 수 있어, 검색 효율이 높다.
